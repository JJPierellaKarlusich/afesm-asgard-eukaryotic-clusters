 
memId_with_gtdbtaxid4137846.Uniprot.tsv.gz
UniProt ID Mapping output (https://www.uniprot.org/id-mapping; release XXXX_XX, accessed [date]) for all 738,717 UniProt accessions assigned to AFESM composite taxon 4137846 (“unassigned Archaea”). For the 688,504 accessions still present in UniProtKB, the file gives the protein name (functional annotation), source organism, NCBI taxonomy identifier and full taxonomic lineage. The 50,213 accessions deleted from UniProtKB have “deleted” in the Protein names field and no other annotation; their taxonomic information, recovered from UniSave, is in the file deleted_memId_with_taxids.tsv. Of the current accessions, 18,659 have lineages containing “Promethearchaeati”, “Asgard” or “Panguiarchaeales” and were classified as Asgard archaea. A further 574,723 have lineages resolved below the domain level that contain none of these labels, and were classified as non-Asgard archaea. The remaining 95,122 are assigned only to the domain level (“uncultured archaeon”, NCBI taxid 115547) and were classified as unresolved Archaea.
Columns (tab-separated, with header):
From: accession submitted to ID Mapping (AFESM member identifier)
Entry: UniProtKB accession (identical to From in all rows)
Protein names: protein name(s) from UniProtKB as functional annotation, or “deleted” for accessions removed from UniProtKB
Taxonomic lineage: full NCBI lineage, from “cellular organisms” to the lowest assigned taxon, comma-separated, with each rank in parentheses
Organism: source organism name
Organism (ID): NCBI taxonomy identifier


deleted_memId_with_taxids.tsv
Taxonomic information for the 50,213 UniProt accessions assigned to AFESM composite taxon 4137846 (“unassigned Archaea”) that have been deleted from UniProtKB. For each accession, the NCBI taxonomy identifier and full lineage were taken from the last archived entry version in UniSave (https://rest.uniprot.org/unisave). All 50,213 lineages resolve below the domain level, and none contains “Promethearchaeati”, “Asgard” or “Panguiarchaeales”. All accessions were therefore classified as non-Asgard archaea.
Columns:
memId: UniProt accession (AFESM member identifier)
taxid: NCBI taxonomy identifier from the archived UniSave entry
lineage: full taxonomic lineage from the archived entry
