# afesm-asgard-eukaryotic-clusters

Code, data, and workflows accompanying:

> Graseck M, Pretorius D, Edwards S, Nikov G, Hamm J, Baum B, Spang A, Ovchinnikov S, Pierella Karlusich JJ.
> **Structural clustering across the tree of life reveals candidate Asgard–eukaryote homologs and a shared expansion of solenoids.**
> *bioRxiv* (2026). https://doi.org/10.64898/2026.10.28.762692

The analyses use protein structure clusters from the AFESM database
(https://afesm.foldseek.com).
