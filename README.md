# afesm-asgard-eukaryotic-clusters
Code, data, and workflows accompanying the study of Asgard archaeal and eukaryotic protein clusters in the AFESM database (*Metagenomic-scale analysis of the predicted protein structure universe*, [bioRxiv 2025.04.23.650224](https://doi.org/10.1101/2025.04.23.650224)).
